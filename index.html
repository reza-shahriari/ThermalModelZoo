Real parts

A single mesh is split into the components the real object has: motor, battery, exhaust, windscreen. Each part can then be given its own temperature in a simulation.

Researched materials

Every part lists what it is made of and an emissivity for the long-wave band, marked measured, reference or estimated so you know how far to trust it.
