Licences & criteria

Which licences are accepted, and why

The zoo exists so that anyone can download a model, change it, and share it again. That only works under licences that allow modified copies to be redistributed, so only four kinds of model are accepted.

This page explains the project's rules in plain language. It is not legal advice; the licence texts linked below are what actually apply.

What we do not accept

Preparing a model for thermal simulation changes it: it is rescaled, split into parts, renamed and given new materials. A licence that forbids modified copies, or forbids commercial use, cannot be honoured by a shared library that people reuse freely.

blockNot accepted

Non-commercial (NC)

Any CC-BY-NC variant. Users of a public library cannot be assumed to be non-commercial.

Rejected at intake
blockNot accepted

No-derivatives (ND)

CC-BY-ND allows sharing only unchanged and whole. Splitting a model into parts is a change.

Rejected at intake
blockNot accepted

Marketplace licences

Standard or royalty-free licences from model stores (for example Sketchfab Standard, TurboSquid, CGTrader) forbid redistributing the model as a file.

Rejected at intake
blockNot accepted

No licence, or unknown

No stated licence means all rights are reserved. Models ripped from games, simulators or CAD sites fall here.

Rejected at intake
A note on real products. A licence covers the 3D file, not the trademarks, logos or designs of the real object it depicts. If a model shows a branded product, the zoo may still need to remove brand marks. When in doubt, say so in the submission.
Attribution

Credit travels with the files

Every download should include an ATTRIBUTION.md naming the author, the original link, the licence and what was changed. Each model page also shows a one-line credit you can copy.

The same fields are published in data/models.json, so tools can read them too.

# ATTRIBUTION

Model:     "Example Quadrotor" (original title)
Author:    Example Author  (https://example.com/profile)
Source:    https://example.com/original-model
Licence:   CC-BY 4.0  (https://creativecommons.org/licenses/by/4.0/)
Changes:   Rescaled to metres; split into 5 parts;
           per-part thermal materials added.
Modified:  Thermal Model Zoo, 2026
Creators & takedown

If something here is yours

If a model was added without your permission, has the wrong licence or credit, or you simply want it removed, tell us. The listing and its files are taken down first and the question is looked into afterwards.

  1. Open a takedown request (link on the right) and name the model and the original work.
  2. The listing is removed from the catalogue.
  3. Files hosted elsewhere are unlinked, and the maintainer asks that host to remove them if the files were uploaded by us.
  4. If the report was a mistake, the entry is restored with corrected credit.
